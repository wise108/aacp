# AACP Transport Profiles

The GitHub transport profile is defined by `github.md` together with the normative ordered-stream semantics in `github-ordered-stream-semantics.md`.

The ordered-stream semantics document is a minimal clarification of allocation/publication lifecycle, retry identity, collision handling, cursor recovery, reconciliation idempotency, and execution uncertainty. It does not introduce a new transport mechanism and does not change AACP Core 1.0.

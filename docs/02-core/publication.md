# AACP Publication 1.0

Publication records whether a result is available to the remote participant through a transport.

Statuses are `PENDING`, `PUBLISHED`, and `FAILED`.

`COMPLETED` task state and `PUBLISHED` publication state are independent facts. A transport that supports remote verification MUST verify remote availability before reporting `PUBLISHED`.

See [SPEC.md](../../SPEC.md) for the authoritative normative requirements.

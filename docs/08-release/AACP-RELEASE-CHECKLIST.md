# AACP Release Checklist

- [ ] Normative specification reviewed
- [ ] Core/transport separation verified
- [ ] Schemas reviewed
- [ ] Conformance suite passes
- [ ] `VERSION` updated
- [ ] `CHANGELOG.md` updated
- [ ] Release candidate validated
- [ ] `v<VERSION>` Git tag created
- [ ] GitHub Release created
- [ ] Tag/release verified remotely
- [ ] Adoption documentation points to the released version

A release is not final until the tag and GitHub Release gates are checked.
